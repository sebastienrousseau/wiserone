## Highlights ⭐️

* **Intact run log**: `docs/logs/wiserone.log` no longer has its first entry overwritten. The completion entry used to be written through a file handle opened before the run, which by then pointed at the start of a rewritten log; it is now appended as the last line.
* **Regression test**: A new test runs the whole application and checks that every log line is a complete entry and that the completion entry appears once, at the end.
