## Highlights ⭐️

* **Current dependencies**: Every dependency is at its latest semver-compatible version, among them config 0.15.26 and thiserror 2.0.21; config's move to json5 1.3 removes the pest parser crates from the build.
* **One nightly dependency issue**: The nightly check keeps a single issue while updates are pending and closes it once the lockfile is current, instead of opening a new issue every night.
* **Accurate update detection**: The nightly check no longer reports updates when there are none; it used to mistake cargo's "Updating crates.io index" line for a package update.
