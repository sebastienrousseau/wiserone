## Highlights ⭐️

* **Safer file handling**: Quote and output paths containing `..` are rejected, the template is checked before it is read, and the sitemap code returns errors instead of panicking.
* **The calibrated quote corpus**: The bundled quotes match the site's 136 hand-calibrated entries, replacing 60 legacy lines, in a single `quotes.json` and `quotes.csv`.
* **Working macros and logging**: `wiserone_min!`, `wiserone_max!` and `wiserone!` work again, and logging moves to rlg 0.0.12 and its builder API.
* **Tag-driven releases**: Releases are cut from signed tags, publish to crates.io through trusted publishing, and every release page carries highlights and checksums.
