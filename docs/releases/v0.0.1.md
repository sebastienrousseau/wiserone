## Highlights ⭐️

* **The first release**: wiserone is a command-line tool and Rust library that turns a collection of quotes into a small static site, one HTML page per quote.
* **JSON and CSV quote files**: Quotes load from either format, so an existing collection can be used without conversion.
* **Random or complete generation**: The CLI writes a page for one randomly selected quote, or a page for every quote in the file, and builds a sitemap for the result.
