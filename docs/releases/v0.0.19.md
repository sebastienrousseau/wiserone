## Highlights ⭐️

* **API docs stop producing duplicate URLs**: Every page on docs.wiserone.com now carries a canonical link, `robots.txt` blocks rustdoc `?search=` URLs and source views, and a generated `sitemap.xml` lists only the current item pages.
* **Daily page mirrored on days 1 to 9**: The CLI and the index refresh now share one zero-padded `YYYY_MM_DD` stem, so `index.html` is refreshed at the start of every month too.
* **Dependencies current**: `log` 0.4.35 and `wasm-bindgen` 0.2.130 with their `js-sys` and `web-sys` companions.
