## Highlights ⭐️

* **Breaking: Rust 1.89.0 or newer**: The minimum supported Rust is now 1.89.0 (was 1.88.0), one floor shared with the maintainer's other Rust crates. The MSRV CI job builds and tests on exactly 1.89.0.
* **MSRV drift fails the preflight**: `scripts/release_preflight.sh` checks that every statement of the minimum Rust version (CI, README, CONTRIBUTING, DEVELOPMENT, `docs/POLICIES.md`) names `rust-version`, and `--msrv` runs that check on its own.
* **Dependabot funnelled**: The GitHub Actions group (#157) lands with this release instead of on `main`.
