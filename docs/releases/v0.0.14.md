## Highlights ⭐️

* **Breaking: Rust 1.89.0 or newer**: The minimum supported Rust is now 1.89.0 (was 1.88.0), one floor shared with the maintainer's other Rust crates. The MSRV CI job builds and tests on exactly 1.89.0.
* **Editorial HTML template and WCAG 2.2 AAA layout**: `_layouts/quote.html` and `index.html` now match the wiserone.com editorial interface with semantic landmarks, WCAG 2.2 AAA contrast tokens, pillar badges, a command-palette search dialog, and zero external CSS/JS framework dependencies.
* **In-crate FIGlet ASCII banner**: `wiserone::ascii` now renders the standard FIGlet font directly in Rust, removing `figlet-rs` and its unmaintained `zip 0.6.6` dependency (`RUSTSEC-2026-0367`, `RUSTSEC-2026-0368`, `RUSTSEC-2026-0369`).
* **MSRV preflight and dependency hygiene**: `scripts/release_preflight.sh` verifies every MSRV statement across the repository, and the GitHub Actions and Cargo lockfile updates land together on this release branch.
