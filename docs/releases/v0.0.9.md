## Highlights ⭐️

* **Escaped quote text**: Every corpus field is HTML-escaped before it goes into a page, so a quote containing `"` or `<` can no longer break out of an attribute or inject markup. Output for the bundled corpus is unchanged; pages for corpora that contain `&`, `<`, `>` or `"` now show those characters escaped.
* **Security assurance case**: docs/ASSURANCE.md sets out the security requirements, threat model, trust boundaries and the weaknesses each countermeasure addresses, including its known limitations.
* **Clear contribution rules**: CONTRIBUTING.md now states the coding standards, a mandatory testing policy and what code review checks, with a pull-request template to match; SECURITY.md adds GitHub private reporting, a response process and reporter credit.
* **OpenSSF Best Practices**: The project is registered at bestpractices.dev, and licence texts are also published under LICENSES/ in the REUSE layout.
