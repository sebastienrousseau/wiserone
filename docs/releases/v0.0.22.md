## Highlights ⭐️

* **A clean dependency check**: `cargo deny` now reports no warnings. rlg 0.0.17 brings euxis-commons 0.0.7, which moved to toml 1.0, so wiserone compiles one copy of `toml`, `serde_spanned`, `toml_datetime` and `winnow` instead of two, and seven licence allowances no dependency uses are gone from `deny.toml`.
* **The unused xtask crate is removed**: nothing in the build, CI or docs ran it, and its lockfile pulled in `atty`, which has two RustSec advisories.
* **The fuzz crate is checked**: CI now runs `cargo deny` on it too, allowing NCSA for `libfuzzer-sys` alone, and fails if its lockfile falls behind the crate it fuzzes.
