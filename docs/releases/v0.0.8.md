## Highlights ⭐️

* **Manpages, completions and provenance**: Releases ship generated manpages, shell completions for bash, zsh, fish, PowerShell and elvish, a CycloneDX SBOM, and a signed build-provenance attestation for every asset.
* **Correct minimum Rust version**: The minimum supported Rust is now stated as 1.88.0, which the dependencies have required since 0.0.6; the previous 1.75.0 did not build. A CI job tests on 1.88.0 so the number stays true.
* **Performance benchmarks that run**: The performance suite (parsing, selection, templating, file I/O) was never registered and never ran; it now does, and docs/BENCHMARKS.md records the results.
* **Code scanning and complexity limits**: CodeQL and OpenSSF Scorecard run on the repository, and CI holds every function to fixed complexity ceilings.
